Rendzu — Five-in-a-Row

Players alternate placing stones. The first to build an unbroken line of five wins (horizontal, vertical, or diagonal). This version uses a 40×40 board.

01 Overview

Rendzu is a classic Five-in-a-Row logic game. Simple rules, deep tactics — especially on a large board.

40×40 note: a large board makes brute force unrealistic. The computer opponent is designed to stay responsive by narrowing candidate moves and using time-budget cutoffs.

Tip: use replay navigation after a game to review decisions.

02 Game Rules

  1. Red always plays first.
  2. Each turn: place one stone on an empty cell/intersection.
  3. First to make five in a row wins (H/V/diagonal).
  4. If no one makes five and the board fills: draw.

06 AI (high level)

The computer opponent uses a minimax-family idea: limited-depth lookahead + evaluation at leaf nodes. On a 40×40 board, the key is restricting move candidates and enforcing time limits to remain responsive.

In practice: consider only meaningful candidates near existing stones, weight them by heuristics, keep top-N, stop on time budget, and play the best move found so far.

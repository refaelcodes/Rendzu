Rendzu — Five-in-a-Row on a 40×40 board

On standard boards you can “think ahead” with brute force a bit. On 40×40, brute force turns into a bonfire. This project showcases a practical AI: minimax-family search + candidate filtering + time-budget cutoffs to guarantee responsiveness.

Board: 40×40
Goal: 5 in a row
AI: minimax-family
Key: weighted candidates
Timer: hard cutoff

Client-facing summary What this proves

  • Branching control: only evaluate moves near existing stones (radius 2–4), depending on difficulty.
  • Heuristic scoring: compute weights for candidate cells and keep only top-N.
  • Difficulty scaling: adjust radius + candidate count + depth/stop criteria.
  • Guaranteed speed: timer cutoff → play best-so-far move.
